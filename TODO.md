# Frame/Photo

For personalised gifts, the user attaches their media in the checkout step. 

But for frames, the user must buy a separate 'photo print' which is not included in the price. Or they could also just decide to buy the frame alone (no photo).

A user may also decide to just buy the photo print (no frame).

- Indicate on frames that a photo print is not included
- After user adds a frame of a certain size to their cart, include a CTA to choose a photo print (auto select size). This must feel desirable.
- On photo print, the user should be prompted to browse all frames. The size of the chosen frame could be subtly indicated to the user based on the photo print in their cart.

# Media
Include basic editing tools (crop, rotate, zoom, grayscale) directly in the browser so users don't abandon the session to edit a photo elsewhere.
